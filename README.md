## 02 // CURRENTLY BUILDING

### FPGA-Based Emergency Keyword Spotting System

**Senior Design Project | In Development**

Developing a real-time, offline emergency keyword
recognition system using a custom FPGA-based neural
network accelerator.

The objective is to detect emergency keywords without
relying on cloud computing or external processing.

```text
 Audio Input
      |
 Analog Signal Conditioning
      |
 ADC Sampling
      |
 DSP Feature Extraction
      |
 DS-CNN Hardware Accelerator
      |
 Keyword Classification
      |
 Emergency Alert
```

### Hardware & Architecture

- Custom RTL-based neural network accelerator
- Depthwise separable convolutional neural network
- Hardware-based DSP feature extraction
- FFT, windowing, and Mel filter banks
- INT8 quantization and structured channel pruning
- RISC-V control and system integration
- Real-time inference on a Xilinx Basys 3 FPGA

### Design Targets

| Specification | Target / Baseline |
|:---|:---|
| Architecture | DS-CNN |
| Model Parameters | ~39K baseline |
| Computation | ~10.6M MACs/inference baseline |
| Numerical Precision | INT8 target |
| Processing | Offline, real-time |
| Application | Emergency keyword detection |

## 03 // BREAKING HARDWARE

### Embedded GPU Reliability Research

> Breaking GPUs to understand how to make them reliable.

Investigating hardware vulnerabilities through
instruction-level fault injection on NVIDIA GPUs,
exploring how bit flips affect computational integrity
and system reliability.

- 4,000 experimental GPU fault injections
- CUDA-based computational benchmarks
- NVIDIA Maxwell GPU architecture
- Silent data corruption and radiation-induced fault models
